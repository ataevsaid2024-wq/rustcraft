# Rust in Minecraft (Fabric 1.21.11)
Кнопка X (меняется в настройках управления) или команды: /mode rust, /mode minecraft, /mode refill
Сборка: залей на GitHub -> вкладка Actions -> build -> артефакт rustcraft-mod.
